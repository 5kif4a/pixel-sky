# Pixel Sky

Локальный прототип авиабоёв с видом от третьего лица на Phaser 3, TypeScript и Vite. Low-poly пиксель-арт, реальный масштаб, модель полёта «условного реализма» (между Ace Combat и War Thunder). Платные сервисы не используются, вся графика создаётся программно.

## Запуск

Требуется Node.js 22.4 или новее.

```sh
npm install
npm run dev
```

Открыть адрес, который напечатает Vite (обычно http://127.0.0.1:5173). В меню выбрать самолёт в карточках слева (сцену у ангара можно облетать мышью, колесо — масштаб) и нажать «Start». Старт в воздухе над морем, бой один на один с ботом. Погода вылета: +25 °C. Язык переключается флагами в правом верхнем углу (английский по умолчанию). Клавиши привязаны к физическим кодам и работают при любой раскладке.

## Управление

| Клавиша      | Действие                                                               |
| ------------ | ---------------------------------------------------------------------- |
| Мышь         | Направление полёта по горизонтали и вертикали (в воздухе)              |
| S / W        | Ручка на себя / от себя: непрерывный тангаж, включая петли             |
| A / D        | Вращение по крену без ограничения угла, включая бочки                  |
| K            | Мышь ↔ прямое управление                                               |
| Q / E        | Руль направления: хвост вправо / влево                                 |
| Shift / Ctrl | РУД больше / меньше (R / F — то же); выше 100 % — форсаж, держится сам |
| H            | Ассист горизонта (без тангажа траектория выравнивается)                |
| G / Z        | Шасси / закрылки (убраны → взлётные → посадочные)                      |
| X / B        | Воздушный тормоз / тормоза колёс                                       |
| ЛКМ / Space  | Пушка (боекомплект конечен)                                            |
| 1            | ИК-ракета                                                              |
| ПКМ / Enter  | Применить выбранное оружие                                             |
| Tab          | Следующая обнаруженная цель                                            |
| V            | ЛТЦ: порция на каждое нажатие, без задержки                            |
| C + мышь     | Свободный обзор; при отпускании C камера сразу возвращается за самолёт |
| T            | Взгляд на выбранную цель (удерживать)                                  |
| Колесо мыши  | Расстояние камеры позади самолёта                                      |
| Esc          | Пауза; N — новый вылет (на паузе или после конца боя)                  |

Взлёт: Shift до форсажа, на ~300 км/ч S, после отрыва G и Z; дальше ведёт мышь. На земле Q/E управляют передней стойкой. Посадка: своя ВПП, шасси выпущено, вертикальная скорость до 3,5 м/с (до 6 м/с — с повреждением шасси). Остановка на своём аэродроме с РУД на малом газе — обслуживание 15 с: топливо, боекомплект, ремонт. Ctrl+W в бою закрывает вкладку — браузер спросит подтверждение.

## Команды

```sh
npm run build          # TypeScript + production-сборка
npm test               # Проверки симуляции (vitest)
npm run test:browser   # Браузерный smoke-тест, dev-сервер должен работать
npm run format         # Отформатировать проект
npm run format:check   # Проверить форматирование
```

## Что есть

- Карта 40×40 км в масштабе 1:1 у побережья Испании: в основном море, на востоке берег с городом, хребтом и двумя аэродромами; рельеф low-poly. Перспективная камера позади самолёта, свободный обзор и взгляд на цель. Мини-карта временно убрана; направление на противника показывает маркер. Высота в основном виде не сжимается.
- МиГ-35, F-16C, Mirage 2000-5: размеры, массы, тяга и скорости из открытых источников (ссылки в `src/data/aircraft.ts`).
- Атмосфера ISA с погодой (температура, давление), тяга и расход топлива по режимам, форсаж, перегрузки самолёта и пилота (G-LOC), сваливание и штопор, взлёт и посадка, закрылки, щиток, шасси, ограничения скорости.
- Модульная модель повреждений: двигатели, баки, крылья, оперение, ЭДСУ, пилот, пушка, боекомплект, шасси, планер; пожары и утечки; повреждения меняют поведение самолёта.
- Пушки с баллистикой и фугасным действием, ИК-ракеты с неконтактным взрывателем и ЛТЦ.
- Один противник ИИ на той же модели полёта и с тем же инструктором, включая ограничения при усталости пилота. Победа — сбить противника.

Радары, ПАРЛ/АРЛ-ракеты, ПВО и конструктор вооружения — следующие этапы. Полный план — в [AGENTS.md](AGENTS.md).
