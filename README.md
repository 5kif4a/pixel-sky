# Pixel Sky

Локальный прототип изометрических авиабоёв на Phaser 3, TypeScript и Vite. Платные сервисы не используются, графика создаётся программно.

## Запуск

Требуется Node.js 22.4 или новее.

```sh
npm install
npm run dev
```

Открыть адрес, который напечатает Vite (обычно http://127.0.0.1:5173). Выбрать F-16 или MiG-35 и нажать «Начать вылет». Для игры нужна клавиатура; управление привязано к физическим клавишам и работает при русской раскладке.

## Управление

| Клавиша                 | Действие                             |
| ----------------------- | ------------------------------------ |
| A / D                   | Поворот                              |
| W / S                   | Увеличить / уменьшить скорость       |
| Q / E                   | Снизиться / набрать высоту           |
| Shift                   | Форсаж                               |
| Space                   | Пушка                                |
| Tab                     | Выбрать следующий самолёт противника |
| F или левая кнопка мыши | Пустить ракету после захвата         |
| Щелчок по самолёту      | Выбрать цель                         |
| B                       | Сбросить бомбу                       |
| C                       | Выпустить тепловые ловушки           |
| Esc                     | Пауза                                |
| R                       | Начать вылет заново                  |

Держите воздушную цель перед носом на дистанции менее 10 игровых километров примерно секунду для захвата. Крест на земле показывает расчётное место попадания бомбы. Три красных квадрата в северо-восточной части мини-карты — обязательные объекты базы. Для победы уничтожьте все три; сбивать перехватчики необязательно.

На голубой базе в юго-западной части карты ремонт и пополнение происходят автоматически: высота ниже 1000 игровых метров, скорость ниже 600 игровых км/ч, нахождение над базой в течение двух секунд.

## Команды

```sh
npm run build          # TypeScript + production-сборка
npm test               # Проверки правил симуляции
npm run test:browser   # Браузерный тест, dev-сервер должен работать
npm run format        # Отформатировать проект
npm run format:check  # Проверить форматирование
```

Для браузерной проверки используется установленный Chrome/Edge или Chromium из Playwright. При необходимости: `npx playwright install chromium`.

## Что уже есть

Два выбираемых самолёта с разной манёвренностью и прочностью; два противника с ИИ; пушка, управляемые ракеты, ЛТЦ и бомбы; изометрическая карта с городом, горами, морем и аэродромами; HUD, мини-карта, пауза, победа, поражение и перезапуск.

Это ранний прототип для проверки ощущений от Phaser. Старт происходит в воздухе, посадка заменена зоной обслуживания. Наземная техника и горы пока декоративные; полноценные ПВО, радиолокация, экранирование рельефом, топливо и ядерный режим ещё не реализованы. Мини-карта показывает всех противников. Звука пока нет. Полный план — в [AGENTS.md](AGENTS.md).

Использован [официальный справочник Phaser](https://docs.phaser.io/phaser/concepts/scale-manager) для настройки масштабирования canvas.
